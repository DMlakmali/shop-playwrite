# Sysco Shop Playwright

A comprehensive test automation framework for Sysco Shop built with **Playwright** and **TypeScript**.

## Overview

This repository contains end-to-end test automation for the Sysco Shop application. It leverages Playwright's powerful testing capabilities to ensure reliable and efficient automated testing of the shop functionality.

## Features

- 🎭 **Playwright Framework** - Modern browser automation and testing
- 📘 **TypeScript** - Fully typed for better development experience
- ⚡ **Fast Execution** - Parallel test execution support
- 🔍 **Multiple Browsers** - Test across Chromium, Firefox, and WebKit
- 📊 **Detailed Reporting** - Built-in HTML test reports
- 🎯 **Page Object Model** - Maintainable and scalable test structure

## Prerequisites

- **Node.js** 18.0 or higher
- **npm** or **yarn** package manager
